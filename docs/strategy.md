# 当前策略全表

本文描述 **现在代码实际会怎么走**，不是任务书原文。几何选址、回合取模、时限缓冲都是策略参数；建造格是否合法以判题器反馈为准。对照规则请看 `docs/rules_verified.md`。

入口：`V1Strategy.decide`（`src/agent/brain.py`）。主代码还分布在 `opening.py`（开局、墙线、炮位、寻路）、`opening_schedule.py`（第一天状态机）、`economy.py`（采矿卖矿、回防判断）、`tactics.py`（战术道具、压力判断）、`pioneer_schedule.py`（开拓者接任务）、`world_intel.py` / `news_memory.py`（新闻）、`treasure.py`（宝藏与商店限制）、`task_solver.py`（自进化解题）。

---

## 0. 总体思路（一页看懂）

- **编制**：1 开拓者 + 2 工人 + 1 基地；武器固定为 **两门火箭炮 + 一门电磁炮**。
- **分工**：开局就把两名工人定为 **施工工**（修墙）和 **经济工**（采矿、卖矿、买券），分工跨回合保持，成员阵亡时自动重选（`opening_worker_roles`）。
- **防御**：**单层墙**（规则不允许双层），共 16 段：迎敌正面一整列，再加两翼延伸到院子后沿，后方竖边开口。
- **夜间两人三炮**：两门火箭挨在一起、共用一个操控位，一人轮流开两门火箭，另一人开电磁炮；机器人没清完前开拓者不接新任务、固定守炮，空出来的第三个人是一名工人，整夜在后院采矿（第三夜起有压力时先在家修墙），敌人贴墙开打也不叫回。
- **索敌**：不按怪物等级排序，按「有效伤害 × 每点伤害价值 + 击杀奖励」选落点；火箭打密集 3×3，电磁炮补刀（第 9.3 节）。
- **升级**：按固定升级计划买券、用券，全队已买未用的券会先抵扣对应步骤，不重复买。**券到手就用**：顺序只决定用在哪门，顺序上的武器等级对不上就用到任意同级武器，不拿着等（第 6.1 节）。
- **经济**：攒够一批再卖；官方预告涨价的矿先囤着；涨价当天经济工清包 → 买券升级 → 再去采矿。
- **开拓者**：自进化任务一旦开始就待到做完（离开任务点即失败）；没任务时顺手用券、让开墙线。夜里（机器人未清完）不接新任务。

## 1. 每回合流水线

1. 保留新闻相关决策事件，其余本回合重写；清空本回合的开拓者调度上下文。
2. `begin_round`：吸收官方新闻/民间传闻；白天清掉「本夜见过威胁」；夜里记录机器人第一次逼近己方的夜间回合（`note_night_contact`，供傍晚卖矿估算）；记录迎敌墙是否被拆；重置当天召唤限额与战术购买集合。
3. `learn_from_last_round`：建造失败按原因冷却。占位 2 回合，原因不明 5 回合，累计 3 次不明或描述像非法才 30 回合；缺石头/金币不封格子。
4. 分路：
   - `0 ≤ round_no < 70` 且有基地 → `plan_opening`（第一天白天，见第 7 节）
   - 其它白天 → `plan_day`（第 8 节）
   - 夜晚 → `plan_night`（第 9 节）；见过本夜威胁后连续空窗达到试探外出阈值，才改走白天决策。
   - 分路之后统一跑 `enforce_held_vouchers`（白天持券必用，见 6.1），任何白天分支都绕不过去。
5. 近敌且低血（≤30 或低于满血 15%）且有药：紧急 `use Medicine`。
6. 输出前 `resolve_actor_conflicts`：按实际执行角色去重。普通动作占用角色 id；炮击占用 `controllerId`。紧急治疗选中后，丢掉该角色负责的炮击及其它冲突动作。只有最终发出的指令进入 `last_sent_command`。
7. 空闲且没在操炮的工人/开拓者：半血以下且有药才 `use Medicine`。
8. `_filter_valid` 丢掉：非工人的 `build/remove/collect`，非开拓者的 `acceptTask/submitAnswer`，以及本地字段校验失败的指令。

每角色每回合至多一条指令。`buy` / 建武器会扣本回合预算副本，超支则取消该指令。夜战 `attack` 挂在 **武器 id** 上，`controllerId` 是操控者。

昼夜假设：一天 70 昼 + 60 夜，模 130。「天数」= `round_no // 130`（0 = 第一天）。`roundNo` 从 0 还是 1 起算未经官方确认，边界回合可能偏一拍。

## 2. 角色与通用规则

| 动作 | 工人 | 开拓者 |
| --- | --- | --- |
| `collect` / `build` / `remove` | 可以（`build` 仅白天） | 本地直接丢弃 |
| `acceptTask` / `submitAnswer` | 本地丢弃 | 可以 |
| `buy` / `sell` / `use` / `drop` / `move` / 操炮 | 可以 | 可以 |
| 背包转交 | 官方没有此接口 | 官方没有此接口 |

满血（任务书表）：工人 220，开拓者 200；墙/炮 1/2/3 级 1000/1500/2000；基地 1500/3000/4500。

- 血量低于满血 50% 且背包有药 → `use Medicine`。路过武器商店、没药、金币够、背包有空 → 顺手买药（10 金），不专门跑一趟。
- **寻路**：8 方向等代价，同回合预留格互斥。临时被队友挡住时，会忽略可移动角色再寻一次。估算「回炮要几步」时不把队友当永久障碍；分配的炮位暂时站不进去就按最近的其它炮位估算（`station_return_detail`），避免开拓者被误判「回不去」而原地打转。
- **夜间避险寻路**（`night_danger_cells` / `night_safe_path`）：夜里要绕开的格子包括防线正面以外的区域、机器人周围 2 格、每个机器人朝基地推进的路线（两侧各 1 格，院子里不算）。夜里去任务点、采矿、去小贩、去商店、回炮位，都先按这个绕行；走不通只避机器人；再不行才走普通路径。夜里在家修墙只在院子里走（`courtyard_path`）。

## 3. 基地布局：院子、炮位、墙线

这些都是候选几何，不是官方蓝/黄区。靠地图边缘时墙线收缩到地图内。

**进攻方向（用户确认，不是任务书）**：基地在地图左半 → 敌人从右来；在右半 → 从左来。

**院子**：基地外扩 `WALL_MARGIN=2` 格的矩形内部，后方竖边不封，作为己方通道。

**炮位**（`weapon_slot_plan`，类型和位置绑定）

| 武器 | 位置 |
| --- | --- |
| 火箭 A | 紧贴正面墙内侧那一列，靠下侧 |
| 电磁炮 | 同一列，靠上侧 |
| 火箭 B | 火箭 A 身后一列，同一行 |

两门火箭左右相邻，有共同的操控邻格（`dual_rocket_stands`），一人站在那里可以轮流开两门。格子被占时在院子空位里兜底。

**墙**（`wall_ring` = `primary_wall_plan`，共 16 段）

- 规则不允许双层墙，只建一层：迎敌正面一整列 + 两翼一直延伸到院子后沿，后方竖边开口。
- 建造顺序：先正面 → 两翼从靠前往后交替展开 → 后沿两个角最后修。
- 第一天/第二天的目标段数（`staged_wall_plan`）由 `wall_feasible_target` 按夜前能完成的量动态决定，至少是最低生存墙（`survival_wall_plan`：正面 6 段 + 两翼各取紧挨正面的 1 段，共 8 段）；第三天起目标是整条 16 段。
- 建某格前 `safe_wall`：建完后三人还能回到各自炮位、外面的人还能进院子、工人还能去商店/石矿、开拓者还能去任务点。否则换下一格。
- 工人站在施工格上会先挪到邻格再 `build`。每段墙消耗背包 1 块石头。

## 4. 工人

### 4.1 分工

| 身份 | 第一天 | 第一晚之后 |
| --- | --- | --- |
| 施工工（builder / keeper） | 建三门武器、采石、修最低生存墙 | **专心修墙**（4.2）；第三天起还负责给低于半血的前排墙升级回血 |
| 经济工（economist） | 采铜铁、卖矿、买/用第一张武器券 | 采矿、卖矿、按升级计划买券用券；第三天起不接围墙任务，只在正面出现关键缺口时帮墙 |

只剩一名工人时他同时承担修墙，不锁定专心修墙。

### 4.2 施工工专心修墙（`builder_on_walls`）

第一晚之后，只要防线（16 段）没修完：

- 不去卖矿、不专程去买券。例外：人正好在商店边、钱够，就顺手买（只花一回合）；手里已有券，照常去用。
- **选矿**：往返距离最短（走过去 + 矿离基地的距离）的石矿。
- **攒够一批再回家**（`keep_collecting_stone`）：人在石矿边、自己加另一名工人手里的石头还不够补完整条防线，就继续采。背包满、离天黑不够「回家 + 把手上石头建完」、或这座矿采空时才停。
- **到家先建完手上的石头**，剩下的缺口慢慢补；不会采一块跑一趟。
- 第三天起，前排墙低于 50% 血时先用升级券/修墙包回血（`maintain_front_wall_health`），再继续补墙；已有武器任务或手里有武器券时不被修墙顶掉。

### 4.3 白天决策顺序（`decide_worker_day`）

1. 低血紧急治疗；正面紧急封堵（`emergency_front_seal`）。
2. **矿价上涨日**（仅经济工，`spike_day_cashout`）：先清空背包（连囤货一起卖）→ 买券回家升级武器/基地/围墙 → 钱花完再回去采矿。
3. 施工工的前排墙回血（第三天起）。
4. **入夜清包窗口**（施工工专心修墙时不走）：能卖完再回防时，先卖掉可卖矿，再买/用武器券。
5. 手里有武器券或已有武器任务：先去买/用（回防前用掉，不带进夜里）。
6. 回防（第 9.1 节）。
7. 施工工专心修墙：顺手买券/用券 → 采石、攒批、建墙。
8. 继续已有的道具任务。
9. **第三天起，墙有缺口时的经济工**：先清空背包（补墙要用的石头留着）→ 金币够就按升级计划买武器/基地券 → 不够就去采矿。
10. 第三天起的结构优先：补阶段墙，再开围墙/基地升级。
11. 该由他买武器券：开工并买/用；金币不够则先卖矿。
12. 正面无紧急缺口、手头有闲钱（≥20 金）：把钱转成升级（`should_spend_surplus_on_upgrades`）。
13. 升级计划走到基地这一步：去买/用基地券。
14. 补当前阶段缺的墙（`replenish_walls(primary_only=True)`）。
15. 其它卖矿触发（第 5 节）。
16. 机会性商店任务（第 6 节）。
17. 三炮齐后补侧翼（经济工第三天起不做）。
18. 战术道具：炸弹 / 眩晕 / 召唤令。
19. `try_build`：先补武器到 3 座，再按施工窗用石头建墙。
20. `profitable_mine`：一人一矿，粘到背包满或矿不再需要才换；单种矿超过背包 80% 就换别的矿种。分数按本趟真正采得完的数量：`min(剩余格, MINE_TRIP_CAP, 入夜/清包前还能采几下) × 报价 / (去程 + 采集 + 回小贩 + 1)`。受新闻禁采的矿不采。
21. 自救或路过买药。

### 4.4 顺路采矿（`en_route_collect`）

带着升级道具往回走时，身边一格内有需要的矿（铜、铁；墙没修完时也采石头；当天禁采的不采），并且「采这一下 + 剩余路程 + 用道具 + 5 回合余量」之后天还没黑，就先采。背包满或拿的是修墙包时不采。避免升级后再专程跑回来。

## 5. 经济：卖矿与囤货

只卖背包里的石/铁/铜，不卖券、药、炸弹。无小贩报价时只按数量触发。已承诺去卖的人（`selling_roles`）会卖完。到了小贩一格内，优先卖「数量 × 报价」最高的那种，一次卖完这一种。

**不卖的部分**

- **涨价前囤货**（`ores_held_for_price_rise`）：官方消息预告 2 天内（`PRICE_RISE_HOLD_DAYS`）会涨价的矿，涨价前一律不卖（开局卖矿、平时卖矿、清包都遵守），也不计入「能换多少钱」的估算。背包达到 90% 满时，只卖掉超过半包的部分，避免采不动。
- **禁采前囤货**：新闻说明天禁采的矿，当天每种最多保留半包。
- **留石**（仅工人）：第一天每人约留 4 块；第一晚后按当前阶段还缺几段墙留够；基地低于 70% 血时至多留 1 块；入夜清包且正面已封时，石头也卖。

**什么时候去卖**

| 模式 | 触发 |
| --- | --- |
| 第一天 | 全队现金 + 铜铁估值够本次必要的券；背包满；铜铁达到 `OPENING_METAL_BATCH`（15）；接近白天截止；两名工人都有铜铁时指定一人去卖 |
| 急用 | 卖掉本包就够必要的武器券；低血携矿；今天涨价的矿 |
| 批量 | 背包过半，或剩余空位 ≤2，或再采一趟就会错过回防前这一趟 |
| 入夜前清包 | 离天黑剩余安全时间落入 12 回合（第三天 20 回合）内、卖完还赶得回来：不管背包满不满都去卖，并优先买/用武器券 |
| 涨价日 / 第三天墙有缺口 | 经济工强制清包（见 4.3 第 2、9 条） |

**卖矿时间判断**（`_sale_fits`）：卖完回到炮位要早于敌人到达。傍晚看不到敌人时，可以借用前几晚实测的「入夜后多久才接敌」（历史最早接敌回合 − 4，最多 12 回合），但必须在天黑前走到小贩并卖完。夜里本夜已见过敌人、当前视野里一个不剩时，按离天亮的回合数判断，夜里外出的工人也能卖。

## 6. 升级：买券与用券

### 6.1 升级计划（`upgrade_plan`）

顺序固定：

> 火箭 A 1→2 → 火箭 B 1→2 → 火箭 A 2→3 → 基地 1→2 → 火箭 B 2→3 → 电磁炮等其余武器 1→2 → 2→3

（火箭 A/B 按离进攻方向远近排序。）

- **已买的券先抵扣**：全队背包里每张没用的券，按顺序抵掉它对应的那一步，这一步不再买。
- **按顺序接着买**：`next_upgrade_step` 从第一个「没被抵扣、也没人正在买」的步骤开始。一次买的张数 = 后面连续需要同一种券的步数（`upgrade_batch_size`），开局买券同样按此。例如有人已买了火箭 A 升 3 级的券还没用，下一个去商店的人直接买基地券。
- **持券必用**（`held_weapon_voucher_target` + `enforce_held_vouchers`）：券 1 只能升 1 级武器、券 2 只能升 2 级武器（规则）。手里有券就在本回合去用，不等：
  1. 目标：按升级顺序找第一门**现在正好是该等级**的武器（第一张券 1 就是火箭 A）；顺序里找不到（例如手里是券 2、火箭 A 还是 1 级而火箭 B 已 2 级）就直接用到任意同级武器，顺序靠前 → 火箭 → 近者优先；同级武器都被别人的任务锁着也照样给。
  2. 执行：白天每回合所有分支出完指令后统一检查，已在一格内直接 `use`，否则走过去；覆盖施工、采矿、清包等任何白天指令，写入 `worker_item_jobs` 让后续回合继续。
  3. 不接管：紧急治疗；本回合正在买武器券（批量买完再去）；开拓者任务进行中；没有同级武器（都已升过或还没到）。同一回合两名持券人不会选同一门。
  4. 夜里：`use` 规则上昼夜都能用；守炮的人在没目标/冷却时就地用身边同级武器的券（`night_voucher_use`）。
- 没买到的武器任务若不是顺序上的下一步，会放掉重新领取；目标武器已超过券的等级则释放任务重挑。
- 基地低血或第三天也不打乱顺序：先把火箭 A 升到 3 级，再升基地。
- **何时算「该升基地」**（`station_first_upgrade_pending`）：计划里基地之前的步骤都已完成、已买券或有人在买，基地这一步还没买券。

### 6.2 两段式道具任务（`worker_item_jobs`，工人和开拓者共用）

1. 背包没有该道具 → 去武器商店 `buy`；背包满则先 `drop` 铜/铁/石（不丢券和药）。
2. 有道具 → 走到目标建筑一格内 `use`；发出后等下一回合结果确认再清任务。
3. 目标建筑没了就释放任务。金币不够：武器券任务保留并继续筹资；其它任务释放。
4. 夜里去商店、去目标旁边都走避险路线；修墙时优先只在院子里走。

**新开任务顺序**（`maybe_start_shop_item_job`）：

1. 手里有武器券：按 6.1 去用。
2. 升级计划的核心步骤（基地及之前的步骤，以及所有 1 级升级）。
3. 基地 1→2（计划走到基地、第二天基地低血且两门武器已到 2 级、或第三天起）。
4. 围墙升级（见 6.3）。
5. 升级计划剩下的武器步骤。
6. 基地 2→3。
7. 已不能再升级（3 级）且即将被摧毁的墙：背包里已有修墙包才派。

同一目标不会被两人重复锁。

### 6.3 围墙升级与修墙

- **只升级残墙**：血量低于 50%（`WALL_UPGRADE_HEALTH_RATIO`）的墙才买券；批量张数也只按这些墙的数量算。
- **先建新墙**：正面有缺口或阶段墙没建完时，离入夜超过 20 回合（`WALL_UPGRADE_DUSK_WINDOW`）前不开围墙升级任务（`wall_upgrade_jobs_allowed`）。第三天起的前排墙回血（4.2）不受此限。
- 第三天起经济工不接围墙任务（涨价日集中升级阶段除外）。
- **升级会回满血**（任务书 4.6.3），所以能升级的残墙优先用升级券；3 级墙即将被摧毁时才用修墙包（10 金）。即将摧毁：近敌两回合伤害就能打掉，或无近敌时血量 ≤80 / 低于满血 15%。

**券名与默认价**（商店快照有报价则用报价）：

| 对象 | 1→2 | 2→3 |
| --- | --- | --- |
| 武器 / 基地 | `WeaponUpgradeVoucher1` / `StationUpgradeVoucher1`，100 | `…Voucher2`，150 |
| 墙 | `WallUpgradeVoucher1`，20 | `WallUpgradeVoucher2`，30 |

**基地券使用时机**：白天基地满血且没挨打时先拿着；机器人贴到基地（距离 ≤2）或基地已掉血、或火箭冷却走得及往返时再 `use`。

**商店限制**（`shop_buy_allowed`）：第四天前只买武器券、围墙券、药、修墙包；基地 1 级券在计划走到基地或第三天起允许；任务用品、召唤令第四天起才买；炸弹/眩晕高压时才买。

## 7. 第一天白天（cycle 0–69）

`plan_opening` 是第一天工人主任务的唯一所有者，实现为有限状态机（`opening_schedule.py`）。`opening_stage` 跨回合持久，只统计存活的武器和墙。

```text
BUILD_WEAPONS → FUND_FIRST_UPGRADE
FUND_FIRST_UPGRADE → APPLY_FIRST_UPGRADE | BUILD_SURVIVAL_WALL | MUSTER
APPLY_FIRST_UPGRADE → BUILD_SURVIVAL_WALL | MUSTER
BUILD_SURVIVAL_WALL → MUSTER
```

| 阶段 | 工人只允许 |
| --- | --- |
| `BUILD_WEAPONS` | 施工工按炮位编制建两门火箭、一门电磁炮；经济工采铜铁/卖矿/买第一张券。经济工无事可做时临时帮忙补建武器 |
| `FUND_FIRST_UPGRADE` | 保留给非首日/恢复态；首日三炮齐后通常不进入 |
| `APPLY_FIRST_UPGRADE` | 持券者走向目标武器用券（顺路可采矿，见 4.4）；快照确认一门武器 2 级后立刻进墙阶段 |
| `BUILD_SURVIVAL_WALL` | 施工工采最近可达石矿，先凑批量石头（`STONE_BATCH`）再集中修墙；经济工继续铜铁 → 卖矿 → 买/用武器券。施工工不可用、墙压迫或临近入夜时经济工转去帮墙 |
| `MUSTER` | 走向分配武器并保持，禁止采矿、出售、购买和远距离施工 |

- 首日三炮齐后立即进入 `BUILD_SURVIVAL_WALL`（`FIRST_UPGRADE_CUTOFF = 0`）；剩余白天 ≤ `MUSTER_BUFFER`(3) 或贴身威胁 → `MUSTER`。
- 第一天墙的最低目标是 8 段生存墙（第 3 节）；时间和石头够就继续往 16 段修。
- 资源目标按真实最短路径选择，每个工人的目标跨回合保持；连续三回合路径不缩短才换目标；检测到来回摆动时保持原目标。
- **个人回防截止点**：每名角色按自己到炮位的真实路程判断，`remaining ≤ own_travel + MUSTER_BUFFER` 就先回炮。背包还有铜铁、且回防前最后绕去小贩卖掉还来得及时，先卖再回。
- 开拓者第一天：有任务就做；三炮齐后若空闲、空包且金币够，可顺手买券升火箭；否则让开墙线和炮位；绝不 `collect` / `build`。

## 8. 开拓者

### 8.1 白天决策顺序（`decide_pioneer_day`）

1. 低血紧急治疗。
2. **自进化任务**（`decide_pioneer_task`）：
   - **进行中的任务**：一直待在任务点直到做完或超时（离开任务点一格外即失败），不因回防、压力、第三夜离开；只做就地治疗。
   - **新任务**：只接有效且冷却为 0 的「自进化类1/2」。条件是 `去程 + 预计解题回合 + 从任务点回炮 + MUSTER_BUFFER` 小于安全截止时间；预计解题回合取经验 p75 与 9 回合的较大值；平台时限太短或预计超时则不接。已在任务点一格内就 `acceptTask`。
3. 回防（第 9.1 节）。
4. 入夜清包窗口 / 被选为买券人时去买券（有任务预约时，只有防守关键的券才中断预约）。
5. 战术道具。
6. **手里有武器券且没在做题**：先按升级计划去用掉。
7. 已有的道具任务；没有可做的自进化任务时，才机会性开墙/基地升级任务（工人正站在商店边时不抢）。
8. 自救 / 路过买药。
9. 让开墙线和炮位（`pioneer_stay_clear`）。

「开拓者有活可干」（`self_evolution_work_open`）只算正在做的、已预约的、或本回合真能接的任务（冷却读 `cold_down_rounds`）；任务点有任务但接不了（回不来、夜里要守炮）不算，否则开拓者会既不做任务也不买东西。

### 8.2 夜里不接任务

机器人没清完之前，开拓者夜里一律不接新任务，固定在守炮名单里（在外面会挨打）。任务点可不可接不影响夜里放不放工人。

唯一例外：天黑前已经开始的任务（`phaseTask` 非空）做完再回炮，这期间两名工人守三炮，不放人去采矿。

试探清波（`night_wave_cleared`）之后改走白天决策，开拓者才恢复接任务。

### 8.3 解题

`PioneerTaskSolver`：沙盒读任务 `.md` → 平台 LLM → 必要时执行沙盒命令 → `submitAnswer`。会话与角色移动分开保存；官方清空 `phaseTask` 才丢会话。每天 LLM 限 3 次；自进化进行中豁免且不计入新闻额度。求解器版本保持在 `f1bfe01`。

## 9. 防守

### 9.1 回防（`defense_due` / `muster_for_night`）

$$
T_{\text{安全截止}} = \min(T_{\text{入夜}}, T_{\text{可见敌人首次贴近关键目标}})
$$

比较：`回炮步数 + MUSTER_BUFFER(3)` 是否仍小于截止时间。切比雪夫距离只是下界，不是官方移动耗时。

- 高压、敌人已贴到基地/炮/墙/人员：立刻回。
- 找不到回路：停止批准新的外出；**不可达不等于 8 回合可达**。
- 已过该角色到位点且夜间未达试探外出条件：回炮（进行中的开拓者任务除外）。
- 首日工人由开局计划按返程集合，不走强制集合（高压除外）。
- 夜里被放出去的人不被这里叫回，由第 9.2 节按敌人距离单独把关。

**高压 `pressure`**：正面已建墙被拆，或基地 7 格内 ≥4 个敌人，或近敌且基地 <60% 血。

### 9.2 夜间两人三炮

**规则**：每晚由两个人守三门炮——一人站在两门火箭共用的操控位，火箭冷却时切到另一门已冷却的火箭（`adjacent_ready_rocket`，只切搭档那门）；另一人开电磁炮。每人每回合仍只能下一条指令。

**唯一判断**（`guns_covered_without`）：排除某人后，其余两人能否覆盖全部武器——每人都要有路到炮位；还在路上的人要在敌人到达前赶到（`步数 + 3 < 敌人距离`），**已经站在炮位旁的人不做这项检查**（否则敌人一贴近就把外出的人叫回，变成三人守家）。第三夜起有压力时改为要求两人已在炮位旁（最多再走 1 步）。被排除的人当前站的格子不算障碍。

**选谁出去**：按「上一回合出去的人 → 分工偏好（前两夜经济工、第三夜起施工工）」排序逐个试，第一个「剩下两人守得住、自己也有事可做」的人出去。偏好的人被炮位夹角堵住（例如站在基地、双火箭、电磁炮围出的死角里）找不到可达的后院矿时，换另一名工人出去，不会因此三人守家。出去的人不需要赶在敌人之前回来。

**第三个人的安排**（`_night_worker_release`，每回合重算）：

| 情况 | 谁空出来 | 做什么 |
| --- | --- | --- |
| 开拓者在做天黑前已开始的任务 | 开拓者（不放工人） | 做完任务再回炮，两名工人守炮 |
| 前两夜 | 经济工（优先） | 去后院按夜间选矿规则采矿（能卖时也去卖），施工工和开拓者守炮。带着石头也不去堵正面缺口（夜里不能建造） |
| 第三夜起，有压力 | 施工工（优先） | 经济工守双火箭、开拓者开电磁炮；施工工在院子里用升级券/修墙包给半血以下的前排墙回血（夜里不能建造）。只修从院子里够得着的墙；手里没道具时不出门买。守炮两人必须已在炮位旁（最多再走 1 步，`NIGHT_REPAIR_GUNNER_TRAVEL`）。没墙可修就去后院采矿 |
| 第三夜起，无压力 | 施工工（优先） | 先修残墙，再去后院采矿 |
| 两人守不住（工人阵亡、有人赶不到） | 无 | 三人各开一门 |

放出去的人这一回合没事可做时，回到开炮名单。

**夜间选矿**（`pick_mine` 夜间分支）：只考虑防线后方、不在危险区的矿，按「走过去 + 矿离基地」最短挑选。

**开炮细节**

- `assign_weapons`：人少炮多时优先让分配覆盖全部武器；人够时里侧的人开里炮、外侧的人开外炮，已在炮边的优先，尽量沿用上一回合。
- 去炮位：先避开机器人进攻路线寻路，走不通再走普通路线；操控位不落在未来墙缺口上。
- 已在炮一格内：按第 9.3 节选落点开火；加特林/火箭的 `targetPos` 个数等于武器等级。
- **没目标或冷却时就地用券**（`night_voucher_use`）：手里有同级武器券、身边有对应武器就升级。基地挨打且手里有基地券、冷却来得及往返时去升基地回血。
- 高压时先扔包里的炸弹/眩晕，不离开炮位去商店。
- 没有分配到炮、也没有其它指令时，最后自救。

**试探外出 `night_wave_cleared`**：本夜见过威胁后，连续 `WAVE_CLEAR_STREAK`(8) 回合没有存活敌人才允许有限外出，改走白天决策；出现敌人立即撤销。这不是官方清波标志。

**就近施工 `night_near_work_allowed`**：见过威胁、当前无怪、连续空窗 ≥ `WAVE_LOCAL_STREAK`(3)、尚未达到清波阈值时，已在炮旁的工人可补紧挨着的正面墙或就近维修。

敌对判定：`health > 0` 且 `target_team` 为空或等于我方。

### 9.3 索敌（`targeting.py`）

不按怪物等级排优先级。按任务书数值，同样的伤害打在中型、小型上拿分和减少墙受到的伤害都更多，BOSS/大型血太厚，只当锚点顺带挨打。

每个候选落点的得分：

```
gain = Σ 每点价值 × min(伤害, 剩余血 − 本回合预计伤害)   # 不计溢出
     + Σ 本发打死的怪 × 积分 × KILL_BONUS(0.5)
每点价值 = (积分 + 攻击力 × 威胁系数) / 满血
威胁系数 = 距我方建筑 ≤3（正在攻击）→ 3；否则按距离从 1 线性降到 0（3→13 格）
```

- **本回合预计伤害表**（`DamageLedger`）：一回合所有武器共用；伤害回合末才结算、武器先于机器人移动，所以直接瞄当前坐标。已在炮位的人先决策，其中火箭先算、电磁炮后算。
- **火箭**：候选格是所有怪及其周围格；逐枚导弹贪心（中心 20、周围 8 格 10），再和「整轮叠在同一格」比较取收益高的。上一轮打残的一圈会因击杀奖励被下一门火箭接着打。
- **电磁炮**：能量 10×等级沿弹道按实际伤害扣减、到落点为止；自然偏向补刀和一线串多只。
- **加特林**：只打弹道上第一只（被挡住的不选）；多发须在同一 90° 锥形内。
- **弹道近似**：格心到连线距离 <0.5 视为在弹道上；官方未给出完整算法，需用日志校准。
- **夜末**：最后 `LATE_NIGHT_ROUNDS`(10) 回合，天亮前打不死（剩余血 > 剩余火力）的怪价值记 0，正在打建筑的除外。
- 所有落点收益都为 0 时不开火（火箭不白白进冷却），转去就地用券。

## 11. 新闻与宝藏

每天白天首回合的官方消息、民间传闻写入跨回合记忆。

**矿石新闻（LLM，启发式暂时关闭）**

## 14. 持久化与日志

`state/build_memory.json`：失败建造点、工人建造目标、道具任务（`worker_item_jobs`）、上一回合指令、`policy_memory`（工人分工、武器分配、卖矿承诺、占矿目标、夜间接敌记录、涨价日阶段、召唤日限额、新闻/宝藏记忆、正面墙是否被拆过、角色存活标记等）。队伍/地图/基地变化或回合回退时清空策略记忆，并重置新闻记忆与解题会话。角色从阵亡变为存活时清掉该人的建造目标、商店任务和旧炮位。

决策原因写在 `logs/` 的 decision 报告里。开拓者每回合在 stderr 打 `PIONEER_TASK` 调度日志（候选任务及被拒原因），排查开拓者不动时先看这一行。

本地校验（`BasicActionValidator`）只拦能确定的字段错误，不能代替官方合法性。

## 15. 刻意没做或未证实

- 多回合整局模拟：没有本地模拟器，墙段数、夜间分工等只做了单回合场景测试，需实战日志验证。
