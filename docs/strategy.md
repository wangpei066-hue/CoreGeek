# 当前策略全表

本文描述 **现在代码实际会怎么走**，不是任务书原文。几何选址、回合取模、时限缓冲都是策略参数；建造格是否合法以判题器反馈为准。对照规则请看 `docs/rules_verified.md`。

入口：`V1Strategy.decide`（`src/agent/brain.py`）。主代码还分布在 `opening.py`、`economy.py`、`tactics.py`、`world_intel.py`、`treasure.py`、`task_solver.py`。

## 1. 每回合流水线

1. 保留新闻相关决策事件，其余本回合重写。
2. `begin_round`：吸收官方新闻/民间传闻；白天清掉「本夜见过威胁」；记录迎敌墙是否被拆；重置当天召唤限额与战术购买集合。
3. `learn_from_last_round`：建造失败按原因冷却。占位 2 回合，原因不明 5 回合，累计 3 次不明或描述像非法才 30 回合；缺石头/金币不封格子。
4. 分路：
   - `0 ≤ round_no < 70` 且有基地 → `plan_opening`（第一天白天；`cycle = round_no % 130`）
   - `cycle ≥ 70` 起停止开局远程经济，走 `plan_night`（无怪不能作为继续裸奔采矿/买券的理由）
   - 其它白天 → `plan_day`
   - 夜晚 → `plan_night`；见过本夜威胁后连续空窗达到试探外出阈值，才改走白天决策。当前刷怪立即撤销外出。未达阈值时只允许炮旁就近补正面墙/维修。有敌人立刻切夜间战斗。
5. 近敌且低血（≤30 或低于满血 15%）且有药：紧急 `use Medicine`。没有可靠伤害数据，日志叫「低血紧急治疗」，不称为下一击致死。
6. 输出前 `resolve_actor_conflicts`：按实际执行角色去重。普通动作占用角色 id；炮击占用 `controllerId`。紧急治疗选中后，丢掉该角色负责的炮击及其它冲突动作。只有最终发出的指令进入 `last_sent_command`。
7. 空闲且没在操炮的工人/开拓者：半血以下且有药才 `use Medicine`（普通自救，仍排最后）。
8. `_filter_valid` 丢掉：非工人的 `build/remove/collect`，非开拓者的 `acceptTask/submitAnswer`，以及本地字段校验失败的指令。

每角色每回合至多一条指令。`buy` / 建武器会扣本回合预算副本，超支则取消该指令。夜战 `attack` 挂在 **武器 id** 上，`controllerId` 是操控者；只改 `commands[角色id]` 不会自动覆盖炮击。

昼夜假设：一天 70 昼 + 60 夜，模 130。`roundNo` 从 0 还是 1 起算未经官方确认，边界回合可能偏一拍。

## 2. 角色能做什么

编制：1 开拓者 + 2 工人 + 1 基地。武器目标 **两门火箭炮 + 一门电磁炮**，每座 25 金。

| 动作 | 工人 | 开拓者 |
| --- | --- | --- |
| `collect` / `build` / `remove` | 可以 | 本地直接丢弃 |
| `acceptTask` / `submitAnswer` | 本地丢弃 | 可以 |
| `buy` / `sell` / `use` / `drop` / `move` / 夜战操炮 | 可以 | 可以 |
| 背包转交 | 官方没有此接口 | 官方没有此接口 |

满血（任务书表，策略自救用）：工人 220，开拓者 200；墙/炮 1/2/3 级 1000/1500/2000；基地 1500/3000/4500。

血量低于满血 50% 且背包有药 → `use Medicine`（回满，无需坐标）。路过武器商店、没药、金币够、背包有空 → 顺手买药（10 金），不专门跑一趟。

寻路：8 方向等代价，同回合预留格互斥。接近墙缺口走院子内侧，不从外侧贴墙。己方寻路不把外层诱敌开口当通道。临时被队友挡住时，会忽略可移动角色再寻一次，避免空转。

## 3. 院子、炮位、墙线

这些都是候选几何，不是官方蓝/黄区。靠地图边缘时墙线收缩到地图内。

**进攻方向（用户确认的刷新，不是任务书）**：基地在地图左半 → 敌人从右来；在右半 → 从左来。换边后按实际坐标再算。

**院子**：基地外扩约 2 格（`WALL_MARGIN=2`）的矩形内部。后方不封死，作为己方通道。

**三门武器位置**（`weapon_slots`，与武器种类无关，只按槽位排布）

1. 院子最后一排（远离进攻方向）上下两侧各一门  
2. 第三门放到另一侧再靠前一格，给迎敌墙内侧留通道  

格子被基地占格或已有建筑占住则跳过；三个槽都不可用时，在院子空位里兜底。

**墙**

- 内层（`primary_wall_plan`）：迎敌正面整列 + 侧翼延伸到后排武器列，后方开口。建造顺序先正面、再外层、再侧翼。  
- 外层（`wall_ring` 多出来的那一列）：再往前两格，中部留一格口。地图边缘放不下第二层则退化为单层。  
- 外层准入（`outer_wall_ready`）：内层完整、墙和三门炮都至少二级、墙血量 ≥80%。  
- 按天截断内层数量（`staged_wall_plan`）：第 0 天约 8 段，第 1 天约 12 段，之后铺满内层。天数 = `round_no // 130`。  
- 建某格前 `safe_wall`：建完后三人还能回到各自炮位、外面的人还能进院子、工人还能去商店/石矿、开拓者还能去任务点。否则换下一格。  
- 工人站在施工格上会先挪到邻格再 `build`。墙消耗背包 1 个石头。

## 4. 道具任务（买券、修墙、升墙、升基地）

两段式，挂在 `worker_item_jobs`（工人和开拓者共用这个字典）：

1. 背包没有该道具 → 去武器商店 `buy`；背包满则先 `drop` 铜/铁/石（不丢券和药）。  
2. 有道具 → 走到目标建筑一格内 `use`；发出后等下一回合结果确认再清任务。  
3. 目标建筑没了就释放任务。金币不够：武器券任务 **保留并继续筹资**；其它任务释放。  
4. 旧存档里未买的基地券，若还有武器/墙可升，会让位。

**新开任务优先级**（`maybe_start_shop_item_job`）：未满 2 级的武器 > 三门炮都到 2 级后升一次基地 > 升墙 > 武器 2→3 级 > 其余基地升级 > 紧急修墙。未买到手的修墙会让位于尚未到 2 级的武器。三炮二级后的首次升基地不让位于三级武器。同一目标不会被两人重复锁。若角色已经持有武器升级券，则优先把券用到可升级武器上，不再因为基地升级优先级而把武器券带进夜里。

**升级会回满血**：任务书 4.6.3 写明「武器、围墙、基地升级后建筑将恢复到满血状态」。因此受损但还能升级的墙优先用升级券，不先买修复包。

**修墙（`use WallFixer`，10 金）**：只在墙**即将被摧毁**且已不能再升级（已 3 级）时用，而且背包里已经有修复包才派，不再专门跑商店排队买。即将摧毁：近敌（射程 3）两回合伤害就能打掉，或无近敌时血量 ≤80 / 低于满血 15%。高压破口且邻格有这种残墙时，战术分支会立刻就近修。没有「把工人石头交给开拓者再建墙」的接口。

**升级券名与默认价**（商店快照有报价则用报价）：

| 对象 | 1→2 | 2→3 |
| --- | --- | --- |
| 武器 / 基地 | `WeaponUpgradeVoucher1` / `StationUpgradeVoucher1`，100 | `…Voucher2`，150 |
| 墙 | `WallUpgradeVoucher1`，20 | `WallUpgradeVoucher2`，30 |

选升级目标：等级更低 → 更靠进攻方向 → 火箭优先于电磁/加特林 → 血更低（升级回满血）。也就是说，同级同侧时优先把升级券给火箭炮。墙不要求先修到 80% 再升。

## 5. 武器升级日程

首日主目标是 **三门基础武器 + 最低生存墙**，不是每回合重算「还能不能升级」。三门基础武器建成后，由跨回合持久的 `opening_stage` 直接进入 `BUILD_SURVIVAL_WALL`；第一门升级只走开拓者空档、已有券或已有现金的并行路径，不让工人为升级券反复采铜铁，当天不再回到筹资。

`weapon_upgrade_due`：

| 天数 | 升什么 |
| --- | --- |
| 第 0 天 | 三门基础武器后立刻修最低生存墙；开拓者空档且金币够时可并行买第一张武器升级券，工人不为此挖铜铁 |
| 第 1 天 | 若还有 1 级武器，优先把第二门升到 2 级；两门 2 级后，基地低于 50% 血则先升基地回血，基地健康则先把第三门武器升到 2 级；三门都到 2 级后先升一次基地，再往 3 级升 |
| 第 2 天起 | 基地仍是 1 级则优先买基地券（白天拿着，挨打/火箭冷却再用）；围住炮和基地的内层墙按能否完工回炮决定，不强求铺满；否则未满 3 级的炮继续升 |

当前代码**没有**把第二天目标写成 13/14/15 段墙，也没有显式按“武器多的一侧”偏置侧翼扩展；实际目标仍是 `DAY2_WALL_TARGET = 12`，墙序由 `primary_wall_plan` 的几何顺序决定：正面优先，然后按内层/侧翼顺序补。你设想的 13/14/15 段与“武器多的一侧优先延伸”属于下一步可改的策略，不是当前已实现逻辑。

**谁去买券**

第二天起调用 `pick_weapon_voucher_buyer`。第一天只指定一名最近商店的存活工人/开拓者买第一张券，不并行第二张。开拓者只有自己被选中才去商店。

缺钱工人：

`C = 到小贩 + 出售 + 到商店 + 购买 + 到建筑 + 使用 + 用券后回炮 + 耽误原工作`

已持券：只算走到目标建筑、使用和回炮。已有 `kind=weapon` 任务的人保持粘性，除非阵亡、路径不可达或赶不上安全截止。

- 开拓者正在做 `phase_task` 不中断。  
- 金币不够时只有背包矿石能补缺口的工人才计入（开拓者不卖矿）。  
- 工人在正面墙缺口未补时，耽误施工加罚；开拓者身旁有可接任务时加罚。  
- 回炮从**用券位置**算；找不到回路则不派。  
- 行程加回防缓冲赶不上 `T_安全截止` 的人不派。

墙券、基地券在前两天低于武器。第三天起：内层墙和基地 1→2 高于新的武器升级。已站在商店格子上的人优先买武器券，避免邻格工人抢单、开拓者改去买药。

基地 `StationUpgradeVoucher1`：白天基地满血且没挨打时先拿着；机器人贴到基地（观测距离 ≤2）或基地已掉血、或火箭冷却走得及往返时再 `use`，升级回满血。冷却不够走一趟则留在炮位开火。这是策略时机，不是官方「必须此时升级」。

## 6. 第一天白天（官方 cycle 0–69；cycle ≥ 70 入夜回防）

`plan_opening` 是第一天工人主任务的唯一所有者，实现为五阶段有限状态机（`src/agent/opening_schedule.py`）。只统计 `health > 0` 的武器和墙。三炮未齐时才规划开拓者任务；角色处理顺序先开拓者后工人。`opening_stage` 跨回合持久，三炮齐后首日直接锁到生存墙，不再每回合按瞬时条件在筹资和修墙之间回退。

合法转换：

```text
BUILD_WEAPONS → FUND_FIRST_UPGRADE
FUND_FIRST_UPGRADE → APPLY_FIRST_UPGRADE | BUILD_SURVIVAL_WALL | MUSTER
APPLY_FIRST_UPGRADE → BUILD_SURVIVAL_WALL | MUSTER
BUILD_SURVIVAL_WALL → MUSTER
```

禁止 `BUILD_SURVIVAL_WALL → FUND`、`APPLY → FUND`、`MUSTER → 任何白天经济阶段`。第一天不跑第二门升级，也不调用 `profitable_mine`。

| 阶段 | 工人只允许 |
| --- | --- |
| `BUILD_WEAPONS` | 建三门初级火箭、去施工位、必要回避。禁止采矿和修墙 |
| `FUND_FIRST_UPGRADE` | 保留给非首日/恢复态的第一门升级流程；当前首日三炮齐后通常不进入该阶段 |
| `APPLY_FIRST_UPGRADE` | 持券者走向目标武器用券；其他人保持安全位置或回基地，不跨图采石。快照确认一门存活武器 2 级后立刻进墙阶段 |
| `BUILD_SURVIVAL_WALL` | 采最近可达石矿，先凑批量石头再集中修最低生存墙，必要时丢掉阻塞容量的铜铁。禁止重新采铜铁和升级筹资 |
| `MUSTER` | 走向分配武器并保持。禁止采矿、出售、购买和远距离施工 |

`opening_time_budget` 只从当前 `opening_stage` 派生允许项，不再用估算在筹资和修墙之间切换。`FIRST_UPGRADE_CUTOFF = 0`，首日三炮齐后立即 `BUILD_SURVIVAL_WALL`；剩余白天 ≤ `MUSTER_BUFFER`(3) 或贴身威胁 → `MUSTER`。

资源目标按每名工人到所有可达候选矿的真实最短路径选择：`score = path_length`；服务器已给出单位售价时才用 `path_length / known_unit_value`。`switch_penalty = 4`，且必须落在合法换目标白名单里。每个工人的 `opening_worker_goals` 跨回合保持；连续三回合路径不缩短才宣布原目标失效。检测到 `A→B→A` 时保持原目标、走当前 BFS 下一步。

**修墙先囤够一批再动身（`opening_wall_work`）**：背包里有石头不代表立刻去建墙——只有满足「背包已满」「攒够 `min(STONE_BATCH, 背包容量, 当前缺口数)` 块」「石矿已经不可达」「临近入夜/回防窗口」之一才会转去 `claim_opening_wall`。否则继续囤，避免变成「采一块、跑回去建一道、再跑回矿点」的单趟搬运。修墙阶段第一天不做工人筹资升级，背包里只要还有铜铁（不等背包塞满）就立刻去卖，卖不出去才 `drop` 腾位置。

`go_mine` / `liquidate` / `replenish_walls` / `muster_for_night` 只提供原子动作，不能自行改战略阶段。最终命令之后只有紧急治疗、近敌战斗、正式回防可以覆盖。

最低生存墙（`survival_wall_plan`）先封正面通向基地/武器/操炮位的缺口，再补两侧端点。死亡墙、死亡武器不计入完成。

**个人回防截止点，不是全队统一 `MUSTER`**：`opening_stage` 到 `MUSTER` 只是最终兜底（剩余白天 ≤ `MUSTER_BUFFER` 或贴身威胁）；在那之前，每名角色按自己到已分配武器的真实路程单独判断——`remaining ≤ own_travel + MUSTER_BUFFER` 就先于全队进入个人回炮，基地附近的人不会被最远的队友拖累提前停工。背包还有铜铁、且回防前最后一次绕去小贩卖掉还来得及（`remaining ≤ role_deadline + 2×小贩往返 + 1`）时，会先卖再回炮，不会把资源原样带进夜里浪费；真到了硬截止点就不再绕路，直接回炮。

### 开拓者首日

1. 三炮未齐：可接开拓者任务。  
2. 三炮齐后进入生存墙阶段；开拓者若没有任务占用、背包没有石头、金币够，可并行去买第一张武器升级券并优先升级火箭炮。  
3. 金币不够时不抢工人去采铜铁；背包有石头时不为了买券丢石头。否则让开墙线/炮位，无事去已分配炮位。  
4. 绝不 `collect` / `build`。

### 工人首日

三炮未齐：金币每座 25，走到空炮位 `build rocket`。没金不改去修墙。

三炮齐后只执行生存墙主资源目标：先采石凑批，再集中修墙。首日墙量达到保底线后，若金币已经足够，工人才可作为备用买武器券；金币不够时不为券改采铜铁。没有指令则记录 `worker_state` / `no_command_reason`，不允许无原因 IDLE。

首日工人 **不走** `muster_for_night` 的第 50 回合一刀切。高压/贴身威胁除外。

## 7. 第二天及以后的白天

`plan_day` 先开拓者后工人，共用同一笔金币预算。

### 第二、三天优先级审计

当前实现大体符合「先保防线，再把钱换成火力」：

1. 第二天（day_index=1）若仍有 1 级武器，会先把第二门武器升到 2 级。
2. 第二天两门武器到 2 级后，如果基地低于 50% 血，`station_low_health_upgrade_pending` 会让基地 1→2 抢在第三门武器之前；如果基地健康，则先把第三门武器升到 2 级。
3. 第二天三门武器都到 2 级后，`station_first_upgrade_pending` 会让第一次基地升级排在武器 2→3 之前。
4. 第三天起（day_index>=2），`structure_priority_day` 让基地 1→2 与阶段墙优先级高于新的武器升级；如果基地仍是 1 级且能买/已有基地券，`defer_new_weapon_for_station` 会阻止继续开新武器升级任务。
5. 墙策略：第二天墙目标当前仍是 `DAY2_WALL_TARGET=12` 的阶段目标；13/14/15 段不是硬门槛，属于有时间、有石头、能按时回炮时尽量补。墙扩展顺序仍是几何顺序（正面优先、再侧翼/外层），没有根据“哪侧武器更多”去优先延伸那一侧。

### 工人顺序（`decide_worker_day`）

1. 低血紧急治疗。正面紧急封堵。  
2. **入夜清包窗口**：能卖完再回防时，先卖掉可卖矿，再买/用武器升级券，然后才回防。  
3. 回防（第 9 节）。按 `T_安全截止` 与回炮工时比较，没有第 50 回合一刀切。来不及卖完则带着矿回炮。  
4. 已持武器券或紧急修墙包才继续商店任务；未买的修复包会释放。缺墙时未买的升墙/基地任务让路给新建。  
5. 若应由工人买武器券：开工并买/用；金币不够则先卖矿。  
6. `replenish_walls(..., primary_only=True)`：当前阶段还缺墙，**优先于升墙和修墙**。清包窗口内只保留迎敌紧急封堵。  
   - 缺石：专程去石矿，不改去挖铜铁。石矿不可达或背包满则放弃本步。  
   - 正面迎敌列（`wall_priority==0`）有缺口：有石就建，不等白天末段。8/12 段上限不能代表正面已经有效。  
   - 正面已封、只剩侧翼/外层：该工人回炮工时不够则留石不建（`allow_build=False`）。`overrun` 只在本昼已经安排施工却入夜仍缺墙时 +2，缺石/采购抢占/不可建造单独记，不当成工时低估。  
   - 夜里满足试探外出条件后：按白天逻辑施工。  
7. 其它卖矿触发（第 8 节）。卖矿往返用同一套 `T_安全截止`，试探外出期间仍查返程。  
8. 机会性商店任务：阶段墙没建完则不新开墙/基地升级。修墙包不再在缺墙时插队去商店买。  
9. 三炮齐后，可补外层（需外层准入；`primary_only=False`）。清包窗口内不扩建。非完整施工窗时 `pick_build_target` 只选正面格。  
10. 战术：炸弹 / 眩晕 / 召唤令。  
11. `try_build`：先补武器到 3 座（随时），再按上面的施工窗用石头建墙。清包窗口内不走这一步。  
12. `profitable_mine`：一人一矿，粘到背包满、清包窗口、矿种不再需要或不可达才换。另一人已占的矿降权，全图只剩一座同类矿时仍可分享。分数按本趟真正采得完的数量：`min(剩余格, MINE_TRIP_CAP, 入夜/清包前还能采几下) × 报价 / (去程寻路 + 采集 + 回小贩寻路 + 1)`。官方新闻若预告某矿明日起停工/禁采/受限，当天背包里已有该矿会触发 `liquidate` 优先卖掉；进入受限窗口后不再把该矿当作普通收入目标。当前阶段石头已经够墙缺口时，不再采石。背包满停止。清包窗口内停止采矿并清掉占矿。`replenish_walls` 与开局采石走同一套 `pick_mine`。
13. 自救或路过买药（不专门跑一趟，避免在商店排队）。

### 开拓者顺序（`decide_pioneer_day`）

1. 低血紧急治疗。入夜清包窗口内先卖掉可卖矿、再买武器券，然后才回防。  
2. 只有被 `pick_weapon_voucher_buyer` 选中才 `decide_pioneer_voucher`。  
3. 包里有可卖矿则变现（通常很少）。  
4. 任务：只接有效且冷却为 0 的「自进化类1/2」，按距离排序。行程 + 超时 + 从任务点回炮 + `MUSTER_BUFFER` ≥ `T_安全截止` 则不接；路径找不到则不接。已在任务点一格内 `acceptTask`。只有自己是采购者时不新接。  
5. 宝藏：第四天起才买任务用品；前三天金币留给升炮。已买到手或第四天后，空闲时买齐并 `summonTreasure`。自进化优先于宝藏；窗口前 15 回合且允许采购时才占用开拓者筹备。  
6. 战术道具。  
7. 已有非武器商店任务，或新开修墙/墙券/基地券（`allow_weapon=False`，避免和专责买券冲突）。  
8. 自救 / 路过买药。  
9. 让开墙线和炮位，否则去分配炮。

解题在 `PioneerTaskSolver`：沙盒读任务 `.md` → 平台 LLM → 必要时再执行沙盒命令（超时 10 秒）→ `submitAnswer`。会话与角色移动分开保存；开拓者回炮或操炮时仍消费本回合 LLM/沙盒回传，但不提交、不新开解题输出。官方清空 `phaseTask` 才丢会话。每天 LLM 限 3 次；自进化进行中豁免且不计入新闻额度。

## 8. 卖矿

只卖背包里的石/铁/铜，不卖券、药、炸弹。无小贩报价时只按数量触发，不假装知道成交价。已承诺去卖的人（`selling_roles`）会卖完；小贩不可达则停止继续采矿。到了小贩一格内，同种矿一次卖完。卖矿往返达到 `T_安全截止` 则取消；找不到回路不批准这趟外出。夜间未达试探外出条件也不外出卖。

**留石**（仅工人）

- 第一天：每人大约留 4 个（按缺口和工人数分摊）。  
- 第一晚后：当前阶段还缺几段墙，就在工人之间留够那么多石头，只卖超出的。  
- 基地血量 < 满血 70% 时留石降到至多 1 个。  
- 背包 ≥90% 时不再因「囤货」卡住不卖。  
- 新闻要求囤的矿，不在涨价窗口内则先不卖。  
- **入夜清包**：正面迎敌缺口已封时，连石头也卖掉；还有迎敌缺口则继续留石给紧急封堵。

**两种模式**

- **急用立即变现**：筹资目标 = 本次必要采购实际价格（`next_weapon_voucher_cost`）。第一天看全队现金加所有存活工人铜铁估值，不要求某一个工人单包够券价；缺报价仍去卖，成交金币以服务器下一帧快照为准。低血携矿；涨价窗口对应矿。  
- **不急用则批量**：背包过半，或剩余空位 ≤2，或再采一趟就会错过回防前这一趟。不再用「估值≥10 / 6个 / 背包20% / 白天20–70清仓 / 基地<80%」任一即跑。  
- **入夜前清包升炮**：卖掉再回防还赶得上、但剩余安全时间已落入 `PRE_NIGHT_CASHOUT_LEAD`(12) / 第三晚前 `PRE_NIGHT3_CASHOUT_LEAD`(20) 时，不管背包满不满都去小贩清掉可卖矿，并优先买/用武器升级券。来不及卖完再回防则放弃这趟，直接回炮。清包窗口内不再采矿、不扩建非紧急墙。

已经站在小贩旁边则就地卖掉可卖矿。到了一格内，优先卖「数量×报价」最高的那种，`num` 为该种全部可卖数量。

## 9. 回防与夜间

**高压 `pressure`**：正面已建墙被拆且敌人离基地 ≤7 格，或基地 7 格内 ≥4 个敌人，或近敌且基地 <60% 血。

**回防窗 `defense_due`**

$$
T_{\text{安全截止}} = \min(T_{\text{入夜}}, T_{\text{可见敌人首次贴近关键目标}}, T_{\text{其他已知威胁}})
$$

比较：剩余工作 + 工作终点到操炮位 + `MUSTER_BUFFER`(3) 是否仍小于截止时间。切比雪夫只是下界，不是官方移动耗时，也未计入射程。

**首日到位点（观测，不是官方昼夜）**：官方仍是白天 70 / 夜晚 60。观测到约 70–80 机器人在走路，2 级火箭约 76 开火。因此 75/76 只保留为注释，**夜防到位与停止远程经济都按 cycle 70**。无可见敌人不能作为 cycle ≥ 70 后继续裸奔经济的理由。

- 高压、敌人已贴到基地/炮/墙/人员：立刻回，优先于历史空窗。  
- 找不到回路：停止批准新的外出，尝试回炮或处理阻塞；**不可达不等于 8 回合可达**。  
- 满足试探外出条件且当前无相关敌人：不回防，去做有限工作（院内施工、近距维修优先；远矿/卖矿仍查返程）。每回合按当前快照重算，不沿用上一回合的安全结论。  
- 已过该角色到位点且夜间未达试探外出条件：一律回炮（留任务点看 `pioneer_should_hold_task`）。  
- 白天有远处敌人时仍取与到位点剩余的最小值，不会因为敌人还远就推迟夜防。  
- 没有独立炮：先回基地旁边。  
- 首日工人仍不走 `muster_for_night` 的强制集合，由开局计划按返程集合（高压除外）。  
- 开拓者回防窗是否留下由 `pioneer_should_hold_task` 决定。未开始的任务始终不在回防期新接。回炮从任务点算。

`two_guns_can_hold`（夜间）：两名存活工人、两门血量过半的炮；当前看不见敌人、高压/破口、BOSS、2 个及以上敌人、或最近敌人距基地 ≤8，都视为两门炮守不住。白天无可见波次，一律按守不住处理。

**夜间一人一炮**

- 里侧的人开里炮、外侧的人开外炮；已靠在炮边（一格内）的优先。分配会尽量沿用上一回合。只有 `pioneer_should_hold_task` 为真的开拓者不占炮。  
- 去炮：先把队友当障碍寻路，走不通再穿过占位。操控位不落在未来墙缺口上。  
- 已在炮一格内：火箭冷却则守着；否则打射程内目标。优先级 BOSS > 大 > 中 > 小，同级打血低的。加特林/火箭的 `targetPos` 个数等于武器等级。  
- 高压时先扔包里的炸弹/眩晕，不离开炮位去商店（`allow_travel=False`）。  
- 没有分配到炮、也没有其它指令时，最后自救。

**试探外出 `night_wave_cleared`**：官方没有一夜单波或清波标志。8 只是未经验证的策略参数，只能叫「满足试探外出的条件」，不能叫确认清波。本夜见过威胁后，连续 `WAVE_CLEAR_STREAK`(8) 回合快照里没有存活敌人才允许有限外出。**当前出现相关敌人立即清零空窗、撤销外出、重算回防。** 开局空波次（还没刷过怪）仍守炮。每个白天开始清掉该标记和空窗计数。

**就近施工 `night_near_work_allowed`**：见过威胁、当前无怪、连续空窗 ≥ `WAVE_LOCAL_STREAK`(3)、且尚未达到清波阈值。此时已在炮旁（切比雪夫 ≤1）的工人可补紧挨着的正面墙或就近维修，不离开炮去采矿。

敌对判定：`health > 0` 且 `target_team` 空或等于我方。

每天白天首回合的官方消息、民间传闻写入跨回合记忆。

## 14. 持久化与日志

`state/build_memory.json`：失败建造点、工人建造目标、商店任务、上一回合指令、`policy_memory`（武器分配、卖矿承诺、开局「只修墙」、召唤日限额、新闻/宝藏记忆、正面墙是否被拆过、角色存活标记等）。队伍/地图/基地变化或回合回退时清空策略记忆，并重置新闻记忆与解题会话。角色从阵亡变为存活时清掉该人的建造目标、商店任务和旧炮位。协议没有比赛 ID，无法区分「同一队伍连续两局都从 round 0 开始」。`worker_item_jobs` 会随记忆落盘。

决策原因写在 `logs/` 的 decision 报告里。自进化每个任务还会在 stderr 打 `PIONEER_TASK` / `task_summary`（实例、prompt 哈希、领取/提交回合、拦截次数、结束原因）。动作合法不等于答案判对。

本地校验（`BasicActionValidator`）只拦能确定的字段错误：未知动作、缺 `targetPos`、越界、`attack` 缺操控者、`summonTreasure` 缺物品、`submitAnswer` 缺答案、升级券/炸弹/眩晕/修墙包缺目标等。不能代替官方合法性。

## 15. 刻意没做或未证实

- 开拓者采矿/建墙（官方角色限制）。  
- 背包物品转交。
